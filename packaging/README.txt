GyozaRec — portable version

This folder contains everything you need: run gyozarec.exe.
The "portable" file keeps settings and captures in this folder:
  data\settings.json   settings
  Captures\            saved images, GIFs and videos
To move the app, copy the whole folder. To uninstall it, delete the folder.
If the folder is not writable (for example inside Program Files), move it elsewhere.
